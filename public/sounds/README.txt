Сюда можно положить настоящие записи звуков — тогда игра возьмёт их вместо синтеза.

Имена файлов (формат mp3):
  ball.mp3     — стук шара о шар
  cushion.mp3  — удар шара о борт
  pocket.mp3   — падение шара в лузу
  cue.mp3      — удар кия по шару

Каждый файл — один короткий удар (0.1–0.5 с), без тишины в начале.
Громкость и высоту игра сама меняет в зависимости от силы удара.
После добавления файлов просто обнови страницу.
