# Тренажёр русского бильярда

Браузерный тренажёр ударов в русском бильярде: 2D и 3D, накат, оттяжка, винт, массе,
подсказка траектории, сохранение упражнений и игра «Свободная пирамида» на счёт.

**Играть:** https://valfad3.github.io/billiard/

## Запуск у себя

```bash
npm install
npm run dev
```

Сделано на JavaScript, Canvas и [Three.js](https://threejs.org/), сборка — [Vite](https://vite.dev/).
